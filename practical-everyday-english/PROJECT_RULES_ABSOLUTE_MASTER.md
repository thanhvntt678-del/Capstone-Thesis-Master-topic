# ABSOLUTE MASTER PRODUCTION COMMAND (supreme — supersedes all earlier rule files where conflicting)

This file is the verbatim, permanent production command for
**EVERYDAY ENGLISH REFLEX BOOK, Lesson 0001 → Lesson 2000**. It applies
automatically to every future `NEXT` without being restated. Where it
conflicts with `PROJECT_RULES.md`, `PROJECT_RULES_V3.md`, or
`PROJECT_RULES_RESTART.md`, **this file wins** — except for the exact
approved curriculum data in `source_reference/MASTER_2000_LESSONS.csv`
(`02_MASTER_2000_LESSONS`), which remains the sequence authority.

## I. Master authority
Curriculum authority: `CLAUDE_BOOK_MASTER_2000_LESSONS_PREA1_TO_B2_RESTART_FINAL.xlsx`,
sheet `02_MASTER_2000_LESSONS` (saved at
`source_reference/MASTER_2000_LESSONS.csv`). For every Lesson, read and
obey: Lesson ID, CEFR Level, Major Domain, Scenario, English/Vietnamese
Lesson Title, Primary Communication Goal, English Word Target, Actual
Bilingual A4 Page Target, Main Character, Secondary Character rule. Never
skip/merge Lessons, change IDs or level boundaries, substitute unrelated
titles, invent a different curriculum, pull future content into earlier
Lessons, or return to the old DGE001–401 files (permanently obsolete).

## II. 2,000-Lesson level lock
0001–0250 A0/Pre-A1 (250) · 0251–0600 A1 (350) · 0601–1000 A2 (400) ·
1001–1400 B1 (400) · 1401–1700 B1+ (300) · 1701–2000 B2 (300). "A0" is a
reader-friendly label only — the CEFR-valid name is always Pre-A1.

## III. Final learning goal — full life-domain coverage, in curriculum order
A complete everyday real-life English reflex communication book, Pre-A1→B2,
so a learner never needs a second general dialogue curriculum because an
ordinary life domain was skipped. Across the full 2,000 Lessons, and only
at the level/position the master curriculum places them, progressively
cover: personal identity, greetings, family, home, daily routines, food and
drink, shopping, money, clothing, neighbourhood, directions, transport,
driving, weather, appointments, phone calls, messages, school/learning,
ordinary workplace interaction, restaurants/cafés, hotels, airports,
travel, health services, pharmacies, fitness, personal services, banking,
deliveries, repairs, customer service, technology, internet/accounts,
entertainment, hobbies, friends, invitations, neighbours, travel problems,
lost property, emergencies, public rules, housing, bills, public services,
cultural etiquette, opinions, preferences, plans, decisions, experiences,
clarification, communication repair, disagreement, boundaries,
negotiation, compromise, unexpected situations, problem solving, everyday
social issues, recommendations, personal goals, relationships, feelings,
sensitive conversations, complex consumer/service interactions. **Coverage
≠ early overloading** — never introduce a topic before its proper
curriculum position and CEFR level (this is exactly what Gate C polices
per Lesson, e.g. Lesson 0001 must not reach for clinic-appointment content,
Lesson 0002 must not reach for Lesson 0013's weather or 0016's work).

## IV. Not a memorisation book
Never a vocabulary book, phrasebook, grammar textbook, translation
exercise, disconnected Q&A list, memorised-script collection, or exam-prep
book. Purpose: UNDERSTAND → RESPOND → FOLLOW UP → CLARIFY → ADAPT → SOLVE →
COMMUNICATE. Higher levels mean adapting known language to new situations,
not just longer sentences.

## V. Two-speaker absolute lock
Every Lesson: **Ms Lan** (fixed recurring main character) + exactly one
named secondary character (Mr/Ms + real name). Never Person A/B, Speaker
A/B, or an unnamed role. Active speakers = exactly 2.

## VI. Reference-first production lock
Never write-then-check. Always: REFERENCE FIRST → VALIDATE LEVEL →
VALIDATE COMMUNICATION GOAL → PLAN INTERACTION → VALIDATE ENGLISH →
VALIDATE TRANSLATION METHOD → WRITE → SELF-QC → RENDER → FINAL QC →
EXPORT.

## VII. Source hierarchy
- **A — CEFR level authority**: Council of Europe CEFR Companion Volume +
  CEFR Descriptors decide Pre-A1/A1/A2/B1/B1+/B2, communicative ability,
  interaction complexity, independence.
- **B — secondary level calibration**: Cambridge English official level
  materials (Pre A1 Starters for the 0001–0250 band) calibrate simplicity
  only — never copy children's curriculum, exam content, or characters
  into this adult/general book.
- **C — English validation**: Cambridge Dictionary (or another
  authoritative reference) verifies meaning, grammatical pattern,
  collocation, usage, register, example usage when uncertain.
- **D — English–Vietnamese meaning check**: Cambridge English–Vietnamese
  cross-checks core meaning and flags possible errors. **Translator output
  is never the final book translation** — never paste machine translation
  in.
- **Environment note**: `coe.int`, `cambridgeenglish.org`, and
  `dictionary.cambridge.org` are blocked by this sandbox's network egress
  proxy (confirmed by direct fetch attempts, all `EGRESS_BLOCKED`). Live
  lookups are not possible from this session — trained knowledge of these
  standards substitutes, applied with equal discipline.

## VIII. Pre-writing gate (all seven must pass before writing)
Gate 1 master row check · Gate 2 CEFR level check · Gate 3 exact scenario
check · Gate 4 primary communication goal check · Gate 5 interaction plan
· Gate 6 English language range · Gate 7 translation method. Only after
all seven pass: write the Lesson.

## IX. Pre-A1/A0 absolute lock
Lessons 0001–0250 must genuinely be Pre-A1, not A1/A2 mislabelled.
Progressively: recognising familiar words/names, very basic personal
information, simple greetings, numbers, dates, time, basic objects,
immediate needs, very simple requests, yes/no responses, very simple
questions, asking for repetition, indicating not understanding, very short
predictable exchanges. Never complex explanations, storytelling,
negotiation, abstract opinion, extended problem-solving, or nuanced
disagreement at Pre-A1.

## X. Setting ≠ objective
A Lesson's setting (shop, street, home, restaurant, clinic, station,
workplace, airport, etc.) never expands what gets taught. If the objective
is "recognising and responding to your name," the dialogue teaches that —
not appointment procedures, directions, waiting order, or medical
consultation just because the scene happens to be near a clinic.

## XI. CEFR progression lock
Pre-A1 very short/concrete/supported · A1 simple interaction on immediate/
familiar topics · A2 routine transactions, familiar activities, short
social exchanges, simple problems/arrangements · B1 increasingly
independent/unprepared interaction on familiar/everyday matters,
experiences, reasons, explanations, travel, common problems · B1+ stronger
sustained follow-up, clarification, paraphrase, repair, disagreement,
boundaries, comparison, negotiation, justification · B2 increasingly
fluent/spontaneous: sustaining conversation, explaining/defending views,
responding to counterarguments, nuance, ambiguity, unexpected turns,
persuasion, negotiation, compromise, register adaptation, resolving
complex everyday problems. Higher level = greater communicative ability,
never just longer sentences.

## XII–XIV. English quality (zero-defect) + natural-English test + full-form
Every sentence must pass spelling, grammar, syntax, punctuation,
collocation, word choice, register, politeness, context, naturalness, CEFR
appropriateness, communicative value — grammatical-but-unnatural,
textbook-awkward, Vietnamese-shaped, machine-translated, or
unnecessarily-advanced English all FAIL. Before inserting any turn: "would
an English speaker reasonably say this in this exact situation?" — if no,
rewrite before insertion, not at final QC. Prefer full forms (I am, do
not, cannot, etc.) for the learning text, but full form must still sound
natural; if it doesn't, rewrite the whole sentence rather than force it.

## XV. Real conversation logic
Every turn reacts logically to the one before. As appropriate to level +
scenario + objective (never forcing every function into every Lesson):
OPEN → ASK → RESPOND → REACT → FOLLOW UP → CLARIFY → CONFIRM → EXPLAIN →
REQUEST → ACCEPT → REFUSE → GIVE REASON → OFFER ALTERNATIVE → REPAIR
MISUNDERSTANDING → PARAPHRASE → NEGOTIATE → COMPROMISE → SOLVE → CONFIRM
OUTCOME → CLOSE.

## XVI–XIX. Vietnamese translation, native test, pronoun lock, translation QC
Never word-by-word. Pipeline: natural English → exact meaning → speaker
intention → real-life situation → relationship → tone → politeness →
natural Vietnamese. Vietnamese owes English nothing in word order,
structure, or word count — only meaning, intention, tone, politeness,
relationship, communicative effect. Before accepting each Vietnamese line:
hide the English, read Vietnamese alone, ask "would a Vietnamese speaker
naturally say this here?" — reject and rewrite anything that reads as
machine-translated, word-for-word, English-grammar-in-Vietnamese-words, or
textbook-unnatural. Pronouns are never a default tôi/bạn mapping — choose
from relationship/age/social distance/politeness/situation (tôi–anh,
tôi–chị, em–anh, em–chị, cháu–cô, cháu–chú, mình–bạn, or another correct
system) and keep them logically consistent within the interaction. Every
Lesson requires: word-for-word errors = 0, English-shaped Vietnamese = 0,
wrong pronouns = 0, wrong register = 0, wrong tone = 0, meaning loss = 0,
unjustified meaning addition = 0, unnatural Vietnamese = 0.

## XX–XXI. Printed format + same-line layout
`Character: English.  Vietnamese.` — no printed `English:`/`Vietnamese:`/
`Tiếng Việt:` labels, ever. Character + English + Vietnamese stay on the
same visual line when width permits; long turns wrap naturally (never
force tiny fonts, split one turn into fake rows, or create a fake new
dialogue row).

## XXII–XXIV. No vocabulary lists, no grammar lectures, no images
Zero Vocabulary/Useful Vocabulary/New Words/Key Words/word=meaning tables
— new language is learned through interaction. Zero standalone grammar
lectures — grammar is encountered and applied through dialogue. Zero
images, image placeholders, image-only pages, or reserved blank image
areas.

## XXV–XXVI. Duplication/padding lock + cross-lesson duplication control
Forbidden: exact duplicates, near-duplicate padding, same template with a
name/number swapped, recycled dialogue skeletons, repeated greetings/
closings purely to inflate word count, meaningless restatement, artificial
extension. Per turn: "does this add a necessary communicative function,
response, clarification, or meaningful variation?" — if no, delete it,
including a second/third instance of a function already fully
demonstrated (repetition-as-padding, not reinforcement — this is exactly
what trimmed Lesson 0002's second "Hi" scene). Before finalising, compare
against relevant previous Lessons: exact cross-lesson duplicates = 0,
artificial template reuse = 0, unnecessary near-duplicate dialogue = 0.
**Exception, explicitly stated**: natural unavoidable high-frequency
expressions ("Hello," "Thank you," "Good morning") may recur whenever
communicatively necessary — the prohibition is on artificial curriculum
duplication, never on ordinary legitimate language reuse.

## XXVII–XXVIII. Word/page targets are editorial, quality overrides them
Pre-A1 ~180–260 words/~2–3 pages · A1 ~260–380/~3 · A2 ~380–520/~3–4 · B1
~520–700/~4 · B1+ ~650–850/~4–5 · B2 ~800–1000/~5. These are editorial
targets, not CEFR rules. **Absolute priority order, never reversed:**
1. CEFR accuracy 2. Exact Lesson objective 3. Natural English 4. Natural
contextual Vietnamese 5. Real communicative value 6. Dialogue logic 7. No
artificial duplication 8. Curriculum progression 9. Word/page target. A
shorter high-quality Lesson beats a longer artificial one — never pad.

## XXIX–XXX. Publication design + page integrity
Consistent professional A4 design throughout all 2,000 Lessons: book
header, CEFR level, Lesson number, English/Vietnamese titles, concise
context, dialogue, footer, automatic page number; navy/deep blue + light-
blue accents, clean typography, consistent margins/spacing/hierarchy —
never childish, never overly decorative. No images, no empty decorative
blocks. Zero blank pages, accidental near-blank pages, heading-only
accidental pages, footer-only pages, empty-table-row padding, fake page
breaks, or page-count manipulation (no unnatural font shrinking, no
unexplained large empty space).

## XXXI. Do not rewrite approved Lessons without cause
Once a Lesson has FINAL QC = PASS and is approved, don't rewrite it just
because a later Lesson is in production. Modify an earlier approved Lesson
only for: a genuine factual/language error, a cross-Lesson duplication
problem, or a necessary curriculum-continuity correction — and when
modifying, preserve all unaffected approved content.
